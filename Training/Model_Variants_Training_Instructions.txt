MODEL VARIANTS TRAINING INSTRUCTIONS
====================================

The active core models are SVM, MLP, and CNN.

Every model notebook is self-contained. Do not upload or rely on any custom
helper Python file.


1. PREPARE GOOGLE DRIVE
-----------------------

Keep the model-variant notebooks together in Google Drive:

- Download Dataset Script.ipynb
- MLAAD Scan & MFCC Analysis Cache.ipynb
- Support Vector Machine Training Script.ipynb
- Multi Layer Perceptron Training Sciprt.ipynb
- Convolutional Neural Network Training Script.ipynb
- Optional Random Forest Baseline.ipynb
- Optional Logistic Regression Baseline.ipynb
- Optional XGBoost Baseline.ipynb
- Optional LSTM Baseline.ipynb
- Optional PCA MFCC Feature Analysis.ipynb
- README.md

Default synthetic MLAAD path:
/content/drive/MyDrive/MLAAD_Project/MLAAD_10pct

Default experiment output path:
/content/drive/MyDrive/MLAAD_Project/outputs

For full binary training, set GENUINE_AUDIO_DIR to the corresponding bona-fide
speech folder.


2. DOWNLOAD THE SYNTHETIC MLAAD SUBSET
--------------------------------------

Run:

Download Dataset Script.ipynb

This step is optional if the MLAAD subset is already available. This notebook
does not download the corresponding bona-fide speech.


3. OPTIONAL PREPROCESSING SMOKE TEST
------------------------------------

Run:

MLAAD Scan & MFCC Analysis Cache.ipynb

This notebook is optional. It scans the synthetic and bona-fide folders, checks
basic quality issues, previews MFCC shapes, and saves simple manifest tables.
It does not create a required shared feature cache. The SVM, MLP, and CNN
notebooks each extract their own MFCC features.

For a quick check, set MAX_FILES_PER_CLASS to a small number such as 40. Leave
it as None for final experiments.


4. TRAIN SVM
------------

Run:

Support Vector Machine Training Script.ipynb

The notebook:

1. Loads or creates the manifest.
2. Creates a stratified 70%/15%/15% split.
3. Extracts MFCCs directly inside the notebook.
4. Aggregates MFCCs into fixed-length vectors.
5. Fits StandardScaler using training data only.
6. Selects SVM hyperparameters using validation data only.
7. Processes the test split only after selection.
8. Writes final metrics, report, model, scaler, and confusion matrix.


5. TRAIN MLP
------------

Run:

Multi Layer Perceptron Training Sciprt.ipynb

The MLP uses aggregated MFCC vectors. It includes a sigmoid binary output,
binary cross-entropy loss, validation monitoring, checkpointing, early stopping,
and training/validation curves.


6. TRAIN CNN
------------

Run:

Convolutional Neural Network Training Script.ipynb

The CNN uses tensors shaped as:

batch x MFCC coefficients x time frames x channel

The MFCC maps are not flattened before convolution. The notebook includes
Conv2D layers, ReLU activations, pooling, dropout, a binary output layer,
validation monitoring, final test evaluation, confusion matrix, training curves,
and saved outputs.


7. OPTIONAL BASELINES AND FEATURE ANALYSIS
------------------------------------------

These notebooks are optional and are not part of the selected core model set
unless you decide to keep them:

- Optional Random Forest Baseline.ipynb
- Optional Logistic Regression Baseline.ipynb
- Optional XGBoost Baseline.ipynb
- Optional LSTM Baseline.ipynb
- Optional PCA MFCC Feature Analysis.ipynb

Random Forest, Logistic Regression, and XGBoost use aggregated MFCC vectors.
LSTM uses MFCC time sequences and is included only as an optional comparison.
PCA is for feature inspection only and should not be described as a classifier.
Logistic Regression is used instead of Linear Regression because the labels are
binary classes, not continuous values.


8. FINAL RUN RULES
------------------

For final coursework results:

- Set SYNTHETIC_AUDIO_DIR to the MLAAD synthetic/deepfake folder.
- Set BONA_FIDE_AUDIO_DIR to the bona-fide speech folder.
- Leave MAX_FILES_PER_CLASS = None for the full dataset.
- Do not tune hyperparameters, thresholds, or architectures after looking at
  test results.

Main outputs are written under:

metrics/   classification reports
figures/   confusion matrices and training curves
models/    checkpoints and fitted scalers
tables/    validation, test, leakage, and subgroup tables
