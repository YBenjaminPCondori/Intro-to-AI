1. CORE EXPERIMENTAL PRINCIPLE
==============================

The final workflow must distinguish three stages:

A. CONTROLLED HYPERPARAMETER SCREENING
- investigate one factor at a time;
- train on the training split;
- evaluate candidate choices on the validation split;
- carry the selected configuration forward;
- treat results as sensitivity/screening evidence, NOT proof of a global optimum.

B. JOINT HYPERPARAMETER OPTIMISATION
- Random Search and Genetic Algorithm (GA);
- both use the SAME evidence-informed search domain;
- both use the SAME training/validation data;
- both use the SAME objective;
- both receive exactly the SAME unique model-evaluation budget;
- their purpose is to capture interactions that sequential screening can miss.

C. FINAL HELD-OUT TEST EVALUATION
- performed only after all model-selection decisions are complete;
- only the final selected-model notebook may compute test performance.
